Security

This website does not steal any information!

Grade Sorting

Explanations to the grade sorting systems.

There are four types of sorting methods presented.

Sorting by Name:

Sorting by name will sort the grades alphabetically. This is useful when you want to find a specific grade quickly.

'Name ▲' sorts from Z to A (Z on the top).

'Name ▼' sorts from A to Z (A on the top).

Sorting by Grade:

Sorting by grade will sort the assignment results (the grade on each assignment) from lowest to highest allowing you to visualize where you're absolutely terrible.

'Grade ▲' sorts from highest to lowest (highest on top).

'Grade ▼' sorts from lowest to highest (lowest on top).

Sorting by Total:

Sorting by total will sort the assignments based of their maximum points.

'Total ▲' sorts from highest to lowest (highest on top).

'Total ▼' sorts from lowest to highest (lowest on top).

Sorting by Weight Categories:

Sorting by weight categories will bunch all assignments of the same weight together. Then each assignment is sorted based on grade percentage within each weight class.

The order is based on the order of the actual weight categories at the top.

'Weight ▲' sorts from first weight to last weight (first on top).

'Weight ▼' sorts from last weight to first weight (last on top).

Pasting Subject Grades

Copy and paste your grades from focus as demonstrated in the following.

  1. Log into focus portal and select the class you would like to use.
  2. Bring up the quarter grades you are going to use.
  3. Start by highlighting the first assignment name (top left).
  4. Then drag (still selecting) to the bottom right of the last assignment in the 'Submit Files' category.
  5. Let go, but do not click anywhere else.
  6. Right click and select 'Copy'.
  7. You may also do ctrl + c OR on a macbook cmd + c (Just make sure to copy somehow).
  8. Now that you have the text copied, come back to this website and click the 'Paste from clipboard' button.
  9. You should see the grades populate below, you are able to change them to see different outcomes.
  10. After every edit, you can click the "Calculate" button so see how your changes affect (if necessary).
  11. (Click here) If you cannot paste with the 'Paste from clipboard' button!
